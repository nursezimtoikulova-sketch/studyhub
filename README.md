# My Study Hub

Personal learning site: Cyber Security (CompTIA Security+ SY0-701 prep + home lab project), Spanish, Chinese, chess and Rubik's cube.

Open `index.html` in a browser, or publish with GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).

Progress is saved in the browser (localStorage). Spanish and Chinese audio are pre-recorded neural voices in `audio/`.
